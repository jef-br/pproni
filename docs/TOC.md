# Pproni docs

Open this folder as an Obsidian vault (Open folder as vault). Every folder has a `TOC.md`.

* [Work state](work-state/TOC.md) — **read first**: what is decided, rejected and still open.
* [Specs](specs/TOC.md) — the design spec: target behaviour, §1-§10.
* [Architecture](architecture/TOC.md) — code documentation: pipeline, modules, routing, single exe.
* [Diagrams](diagrams/TOC.md) — `JBA2B.drawio.svg`; edit it with the VS Code Draw.io extension.
* [Analysis](analysis/TOC.md) — reports and measurements (images local only).
* [Agent knowledge](agent-knowledge/TOC.md) — agreed facts the project's agents run on.
* [Notes](notes/TOC.md) — loose notes and ideas.

Links are plain relative markdown links (`[text](path.md)`), so they work in Obsidian, on GitHub
and in the link check (`python tools/check_docs.py`).
